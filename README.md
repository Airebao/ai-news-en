# AI news digest (EN)

Read AI industry news from the last 24 hours or several days. Use for requests such as what happened in AI today or what AI news is worth following.

| | |
|---|---|
| 版本 | `1.7.0` |
| 站点 | [https://aitop.news](https://aitop.news)（AITOP） |
| SkillHub | https://skillhub.cn/skills/user_507a5056/ai-news-en |
| 仓库 | https://github.com/Airebao/ai-news-en |

## 安装

```bash
skillhub install ai-news-en
```

也可以直接把 `SKILL.md` 放进你的 skill 目录——它是完整的 skill 正文，
里面写明了 Base URL、请求头和参数约定。

## 文件

- `SKILL.md` — skill 正文（frontmatter 的 `name` / `description` 即安装入口）
- `_meta.json` — 发布元数据（slug / version / displayName / summary / license / edition）
